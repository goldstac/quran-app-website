# Quran app website

The public website for the **Quran** app: what it does, screenshots, and download buttons that point at the app's releases.

The app itself lives in [goldstac/quran](https://github.com/goldstac/quran). This repo is only the site, nothing more.

## Status

Early setup. The repo, the docs, and the task board exist; there is no site in here yet. See [task-board.md](task-board.md) for what is planned and what is open.

## What goes on the site

- A hero with the app logo and one line about what it is: all 114 surahs with 170+ reciters, plus nasheeds, playlists, and offline listening
- Download buttons for Linux, macOS, and Windows, taken from the app's GitHub releases
- A features section using the real feature list from the app README, not invented marketing
- A few screenshots of the actual app
- Links to the app repo, Discussions for questions, and the privacy and terms pages

Everything on the site has to match what the app really does. If a feature does not exist yet, it does not go on the site.
